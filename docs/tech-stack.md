# ParentPal 技术选型对比

> 目标：**一套代码**同时产出 ① iOS/Android App ② 微信小程序 ③ 桌面端（Windows/macOS）。
> 产品形态：记录 + 提醒 + 内容推送，重表单、重时间线、轻实时，图表为主无重动画。

## 一、候选方案

| 方案 | 语言/框架 | 一套代码覆盖 | 结论 |
|---|---|---|---|
| uni-app | Vue 3 | 小程序(微信/支付宝/抖音) + App(5+/App-Android&iOS) + H5 | ✅ 主力候选 |
| Taro | React | 小程序 + H5 + App(React Native) | ✅ 备选候选 |
| Flutter | Dart | App + 桌面（原生级） | ❌ 无法编译微信小程序，出局 |
| 原生/多套代码 | 各端原生 | 小程序 + RN App + Electron | ❌ 三套代码，违背"一套代码"初衷 |
| Ionic + Capacitor | TS/Web | App + 桌面 + PWA | ❌ 无法产出小程序，出局 |

> 结论先行：**主推 uni-app（Vue 3）**；若团队 React 更强则选 Taro。Flutter 除小程序外全优，若未来砍掉小程序诉求可整体迁移过去。

## 二、uni-app vs Taro 详细对比

| 维度 | uni-app（Vue 3） | Taro（React） |
|---|---|---|
| 小程序端 | ★★★★★ 官方主打，微信/支付宝/抖音/百度全平台，编译产物最贴近原生小程序 | ★★★★☆ 成熟，但部分第三方组件需小程序版适配，偶有编译坑 |
| App 端 | ★★★★☆ 基于 5+/App 原生渲染（也有 uni-app x 新引擎），本地通知、后台、数据库 API 开箱即用；官方 HBuilderX 一键云打包 | ★★★☆☆ 需走 React Native 路线，要配 RN 环境，原生模块（通知/后台）接入成本明显更高 |
| 桌面端 | ★★★☆☆ H5 产物 + Electron/Tauri 包裹，本项目（表单+图表）体验无损 | ★★★☆☆ 同样 H5 + Electron 包裹 |
| UI 组件库 | uView Plus / uni-ui，uni_modules 插件市场极大，轮子多 | taro-ui / NutUI / antd-mobile 移动版，React 生态组件需自行适配小程序 |
| 学习成本 | Vue 模板式语法，新手 1-2 周可上手 | React Hooks + 多端条件编译，门槛略高 |
| 国内社区/招聘 | Vue 系开发者基数最大，资料最多 | React 系，大厂用得多 |
| 后端配套 | **uniCloud**（阿里云 serverless，云数据库/云函数/推送一体，零运维起步） | 通常自建后端（Node/Java + DB） |
| 包体/性能 | 小程序端包体优化手段成熟；App 端渲染层方案略重 | 小程序端轻量；App 端 RN 性能好但工程复杂 |

## 三、针对本项目的能力红线（重要）

1. **定时提醒的可靠性分层**
   - App 端：本地通知 + 推送，可做可靠的循环提醒（喂奶间隔、哄睡、体检预约）✅
   - 小程序端：仅支持"订阅消息"，需用户每次授权、有时效与次数限制，**无法做长期定时提醒**，只能做"打开即计算到期"的弱提醒 ⚠️
   - 设计对策：提醒为 App 的核心能力，小程序端定位为"快捷记录 + 查看"，需在需求文档中明示。
2. **桌面端定位**：H5 包 Electron（后期可换 Tauri 减小包体），适合记录与报表查看，不承担提醒职责。
3. **图表**：ucharts（uni-app 生态首选，全端兼容）或 uCharts 替代方案，睡眠/喂奶统计用它。
4. **数据隐私**：0-3 岁儿童数据属敏感个人信息，本地优先存储 + 可选云同步，隐私政策需在文档中预留。

## 四、推荐技术栈（若选 uni-app）

```
前端：uni-app (Vue3) + Vite + uView Plus + ucharts + Pinia
后端：uniCloud（云数据库/云函数/统一推送）—— MVP 阶段零运维
      （后续要迁自建：Node.js + PostgreSQL）
多端产出：
  - App：HBuilderX 云打包 / 自定义基座（本地通知、后台保活）
  - 小程序：微信开发者工具上传
  - 桌面：H5 产物 + Electron（后续可 Tauri）
```

## 五、待决策项

- [ ] 团队熟悉 Vue 还是 React？（决定 uni-app / Taro）
- [ ] MVP 是否需要云同步/多成员家庭？（决定 uniCloud 还是纯本地）
- [ ] 小程序端是否接受弱化版提醒？
