# ParentPal 需求文档

| 项 | 内容 |
|---|---|
| 产品名 | ParentPal · 家长伙伴 |
| 定位 | 新手父母的科学养娃助手：记录 + 提醒 + 按月龄知识推送 |
| 目标用户 | 0-3 岁宝宝的父母（宝妈为主，宝爸共用） |
| 端 | App（iOS/Android）、微信小程序、桌面端（一套代码，详见《技术选型》） |
| 版本 | v0.1 草案 · 2026-10-13 |

---

## 1. 用户角色

- **主要用户（宝妈/宝爸）**：记录与查看宝宝日常、接收提醒、阅读育儿指导。
- **家庭成员（扩展）**：通过分享码加入，共同记录（M3）。
- **宝宝（被记录对象）**：支持多宝宝档案（二胎家庭）。

## 2. 功能需求

### 2.0 基础模块

- **宝宝档案**：昵称、性别、出生日期/时间（自动算月龄与日龄）、出生体重身长、预产期（可选）、头像。
- **多宝宝切换**：顶部/设置中切换当前宝宝，数据按宝宝隔离。
- **首页·今日总览**：当前宝宝卡片（今天 X 月 X 天）；今日四类记录汇总（睡眠总时长/喂奶次数与总量/便便次数/上次记录时间）；今日待办提醒（下次体检倒计时、到点未睡、距上次喂奶时长）。
- **数据导出**：按月导出 CSV/图片报表（M2）。

### 2.1 发育体检模块 ⭐

**体检时间表**（依据国家基本公共卫生服务 0-6 岁儿童健康管理规范，覆盖 0-3 岁）：

| 月龄 | 阶段 |
|---|---|
| 新生儿期 | 出院后 1 周内家庭访视 + 满月（28-30 天）体检 |
| 3 月龄 / 6 月龄 / 8 月龄 | 婴儿期体检 |
| 12 月龄 | 周岁体检 |
| 18 月龄 / 24 月龄 / 30 月龄 / 36 月龄 | 幼儿期体检 |

**核心能力**：
1. 依据宝宝生日**自动生成全周期体检计划**，每次体检显示：建议体检日期、倒计时、状态（待体检/已预约/已完成/已跳过）。
2. **提前提醒**：默认提前 7 天 + 提前 1 天推送（可配置），App 本地通知。
3. **每次体检详情**（内容库维护）：
   - 检查范围：体格测量（身长、体重、头围）、体格检查（皮肤、心肺、腹部、生殖器、髋关节）、发育评估（大运动/精细动作/语言/社交行为，参考 DDST/ASQ 类量表）、营养与喂养指导、相应月龄筛查项（如 6/12 月龄听力行为观察、18 月龄血红蛋白、30 月龄血常规、36 月龄视力筛查等，标注"按当地社区与医嘱执行"）。
   - 考察项目清单（逐项 checkbox，家长可自查预习）。
   - 就诊贴士（携带证件、疫苗本、常见问答）。
4. **结果归档**：记录体检日期、机构、测得数据（身长/体重/头围），自动绘制成长曲线（WHO/中国标准），自动推算下次体检时间。

### 2.2 哄睡提醒与睡眠记录 ⭐

- **哄睡提醒**：
  - 按"清醒间隔（awake window）"智能提示该哄睡了（按月龄默认表：0-3 月 45-90 分钟、4 月 1.5-2h、6 月 2-2.5h、9 月 2.5-3h、12 月 3-3.5h、18 月 3.5-4.5h、24 月+ 5-6h，可手动调整）。
  - 用户也可自定义固定作息提醒（如 20:00 开始哄睡）。
- **记录**：入睡时间、醒来时间（自动算时长）、夜醒次数与时长、入睡方式备注（奶睡/抱睡/自主）。
- **统计**：日/周/月睡眠总时长、白天小睡次数 vs 夜间睡眠分布、夜醒趋势折线图。
- **建议**：按月龄推荐睡眠总时长（参考 NSF 指南：0-3 月 14-17h、4-11 月 12-15h、1-2 岁 11-14h、3 岁 10-13h），持续低于下限时给出作息调整建议（非医疗建议免责声明）。

### 2.3 喂奶提醒与记录 ⭐

- **记录方式**：
  - 母乳：左侧/右侧/双侧 + 单侧时长（计时器）。
  - 奶粉：奶量（ml）+ 品牌/段数备注。
  - 混合喂养自动归类；辅食记录（M2 扩展：食物种类）。
- **喂奶提醒**：按上次喂养结束时间 + 月龄默认间隔（新生儿 2-3h、3-6 月 3-3.5h、6-9 月 3.5-4h、9-12 月 4h+，可调）到期推送；支持"提前/延后 15 分钟"快捷操作。
- **统计**：今日喂养次数、总奶量（估算母乳量换算）、间隔分布、与推荐摄入量对比（按体重参考值）。

### 2.4 排便记录 ⭐

- **记录**：时间、性状（选择器）、量（少量/中量/多量）、备注。
- **性状选项**：金黄糊状（母乳正常）、黄色软膏（奶粉正常）、绿色、奶瓣、稀水样、泡沫、黏液、干硬/便秘、血丝、其他。
- **智能提示**：出现"稀水样/血丝/持续 3 天未排便/便次骤增"等，弹出观察建议与就医提示（免责声明）。

### 2.5 育儿指导推送 ⭐

- **按月龄内容库**（0-36 月，每月一条主内容 + 若干子卡片）：
  - 本月发育里程碑（大运动/精细/语言/认知/社交五维）。
  - 亲子互动建议（具体到游戏玩法与频次）。
  - **音乐启蒙**（重点栏目）：本月龄适合的音乐类型与曲目建议——如 0-6 月白噪音与轻柔古典（舒伯特《摇篮曲》、莫扎特《小夜曲》）、6-12 月节奏性儿歌与律动、12-24 月简单打击乐与动物狂欢节类曲目、24-36 月音乐游戏与奥尔夫节奏练习；附"不建议"清单（长时间高分贝、电子屏幕儿歌等）。
- **推送策略**：进入新月份自动置顶推送；每周精选 1 条；用户可收藏/标记已读。
- 内容运营后台（M3）：内容 CMS 化管理。

## 3. 非功能需求

| 类 | 要求 |
|---|---|
| 平台 | 一套代码产出 App / 微信小程序 / 桌面端（见技术选型）；提醒能力以 App 为准，小程序端为弱化版（订阅消息限制，需明示） |
| 隐私合规 | 儿童敏感个人信息：本地优先、可导出可删除、隐私政策与儿童个人信息保护规则需法务确认 |
| 离线可用 | 全部记录功能离线可用，联网后同步 |
| 可靠性 | 本地通知需在 App 杀后台/重启后仍可按计划触发 |
| 性能 | 首页加载 < 1s；记录页 2 步内完成一次记录 |
| 数据 | 本地 SQLite + 云端备份（M3）；云端数据加密 |

## 4. 数据模型（简版）

```
babies            宝宝档案（id, 昵称, 性别, 出生时间, 出生体重/身长, 头像）
checkup_plans     体检计划（baby_id, 月龄阶段, 计划日期, 状态）
checkup_records   体检结果（baby_id, 日期, 机构, 身长/体重/头围, 备注）
sleep_records     睡眠记录（baby_id, 入睡/醒来时间, 时长, 夜醒次数, 方式备注）
feeding_records   喂养记录（baby_id, 类型[母乳/奶粉/辅食], 侧/时长, 奶量ml, 时间）
stool_records     排便记录（baby_id, 时间, 性状, 量, 备注）
reminder_rules    提醒规则（baby_id, 类型[体检/哄睡/喂奶], 参数JSON, 开关）
parenting_tips    育儿内容库（月龄, 分类, 标题, 正文, 曲目建议JSON）
```

## 5. 里程碑

| 阶段 | 范围 |
|---|---|
| **M1（MVP，4-6 周）** | 宝宝档案、四类记录（睡眠/喂奶/便便/体检提醒）、首页总览、App 本地提醒、ucharts 基础统计 |
| **M2（6-8 周）** | 成长曲线、睡眠/喂奶智能建议、育儿指导内容库、数据导出、小程序端发布 |
| **M3** | 家庭共享、云同步、内容 CMS、桌面端正式发布、App Store 上架 |

## 6. 待确认问题

1. 团队更熟悉 Vue 还是 React？（决定 uni-app / Taro）
2. MVP 是否需要云端同步，还是纯本地？（影响后端工作量 3-5 周）
3. 小程序端是否接受弱化提醒并明确告知用户？
4. 体检/睡眠/喂奶建议的医学口径：是否接入儿保医生做内容审校？
5. 商业化方向（免费+会员？）——影响是否引入支付模块。
